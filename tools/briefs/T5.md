## Goal
`gdpins_go_offline()` / `gdpins_go_online()` for boards use the single local copy. Remove the
local→cache catch-up loop. `drive_only` cannot go offline.

## Design excerpt
`gdpins_go_offline.gdpins_board` (R/offline.R 83–123):
- `local_only` → inform + return `x` (unchanged; also covers double go_offline).
- `drive_only` (`identical(x$config, "drive_only")`) → `cli::cli_abort(c("Board {.val {x$name}} has no local copy ({.code cache_dir = FALSE}); cannot go offline.", i = "Re-initialise it with a {.arg cache_dir} path to work offline."))`.
- `drive_cache` → stash `offline_state <- list(config = x$config, drive_board = x$drive_board, cache_dir = x$cache_dir, drive_path = x$drive_path, adapter = x$adapter)`;
  return `new_gdpins_board(config = "local_only", name = x$name, local_board = x$local_board, cache_dir = x$cache_dir, versioned = x$versioned)` with the attr.
`gdpins_go_online.gdpins_board` (202–245):
- delete `is_super`, `local_dir`, and the `.copy_pin_to_board` catch-up loop entirely.
- `board <- new_gdpins_board(config = state$config, name = x$name, drive_board = state$drive_board, local_board = x$local_board, cache_dir = state$cache_dir, drive_path = state$drive_path, adapter = drive_adapter, versioned = x$versioned)`.
- rest unchanged (`.handle_init_sync`, inform).
Do NOT edit the roxygen block lines 1–63 (T8 owns docs/example). Raw-conn methods unchanged.
