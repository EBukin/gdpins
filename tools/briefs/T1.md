## Design excerpt
`gdpins_init_board()` signature unchanged: `name, drive_path = NULL, cache_dir = NULL, local_dir = NULL,
versioned = TRUE, create = NA, on_discrepancy = NULL, adapter = NULL, lazy = NULL`. You do not edit it.

`.board_spec()` signature unchanged (`name, drive_path, cache_dir, local_dir, versioned, create,
on_discrepancy, adapter`). New behaviour, in this order after existing name/versioned/on_discrepancy checks:
1. `local_dir` non-NULL → `lifecycle::deprecate_warn(when = "0.0.1.9024", what = "gdpins_init_board(local_dir)",
   with = "gdpins_init_board(cache_dir)", details = <see below>)`.
   If `cache_dir` is NULL → `cache_dir <- local_dir`, `details = NULL`.
   If `cache_dir` non-NULL → keep `cache_dir`, `details = "Both `local_dir` and `cache_dir` were supplied; `local_dir` is ignored."`
   (text must name both args).
2. Validate `cache_dir`: allowed = `NULL`, `TRUE`, `FALSE`, or `character(1)` non-NA, `nzchar`.
   Anything else (`""`, `NA`, `NA_character_`, `c("a","b")`, numeric, `logical(0)`) →
   `cli::cli_abort("{.arg cache_dir} must be {.code NULL}, {.code TRUE}, {.code FALSE}, or a non-empty path.")`.
3. Decision table:

| `drive_path` | effective `cache_dir` | config | spec `cache_dir` |
|---|---|---|---|
| NULL | character | `local_only` | that path |
| NULL | NULL / TRUE / FALSE | abort: "Supply {.arg drive_path}, or {.arg cache_dir} as a path for a local-only board." | |
| path | NULL / TRUE | `drive_cache` | `.default_cache_dir(adapter, drive_path)` |
| path | character | `drive_cache` | that path |
| path | FALSE | `drive_only` | `NULL` |

   `drive_path` non-NULL and `adapter` NULL → existing abort ("{.arg adapter} is required when
   {.arg drive_path} is supplied." — keep text) — check BEFORE computing default path.
   Remove the old "cache_dir is required" abort and old "At least one of drive_path or local_dir" abort.
4. Return list, EXACT names/order: `name, drive_path, cache_dir, versioned, create, on_discrepancy, adapter, config`
   (no `local_dir`).

`.default_cache_dir(adapter, drive_path)` (new, `@keywords internal`, in `R/board.R` right after `.config_components`):
- root = `getOption("gdpins.cache_dir")`.
- key = `adapter$root_id` if `identical(adapter$kind, "real")`, else `basename(adapter$root)`.
- components = `strsplit(drive_path, "/")[[1]]`, each `gsub("[^A-Za-z0-9._-]+", "_", x)`; then drop
  empty strings; and replace components that are exactly `"."` or `".."` with `"_"` (path traversal guard).
- result = `as.character(do.call(file.path, c(list(root, key), as.list(components))))`.
- Pure: no FS calls.
