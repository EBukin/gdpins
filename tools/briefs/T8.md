## Design excerpt
- `cache_dir`: `NULL` (default) or `TRUE` → `getOption("gdpins.cache_dir")/<adapter root>/<drive_path>`
  (option default `~/.gdpins/cache` via `fs::path_home()`); a path → that path; `FALSE` → no local copy
  (`"drive_only"`; Drive downloads go to a session temp dir; cannot go offline). For a board without
  `drive_path`, `cache_dir` is the local board path (`"local_only"`).
- `local_dir`: deprecated in 0.0.1.9024; used as `cache_dir` when `cache_dir` is NULL, ignored otherwise.
- Configs: `local_only`, `drive_cache`, `drive_only`. Fields `cache_board`, `local_dir` removed.
- Write → Drive then local copy; read → local copy then Drive; sync compares Drive vs local copy.
