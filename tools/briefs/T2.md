## Design excerpt
`.build_board(spec)`:
- `local_only`: `fs::dir_create(cache_dir)` if missing; `local_board <- pins::board_folder(cache_dir, versioned)`;
  `new_gdpins_board(config="local_only", name, local_board, cache_dir, versioned)`.
- Drive configs, offline (`gdpins_is_online()` FALSE/error):
  - `drive_cache` → existing warning ("No internet connection detected." …), then `local_only` board over
    `cache_dir` (dir_create), with `cache_dir = cache_dir` (unchanged path). drive_path/adapter not stored (as today).
  - `drive_only` → `cli::cli_abort(c("Drive board {.val {drive_path}} is unreachable offline and has no local copy ({.code cache_dir = FALSE}).", i = "Reconnect, or initialise with a {.arg cache_dir} path."))`.
    No warning first.
- Drive configs, online: existence/create dance UNCHANGED. Then:
  `scratch <- if (config == "drive_cache") cache_dir else tempfile("gdpins_scratch_")`; `fs::dir_create(scratch)`.
  Fake adapter → `board_folder(<adapter$root>/<drive_path>)` (as today). Real → `pins::board_gdrive(as_id(id), cache = scratch)`.
  `local_board <- if (config == "drive_cache") pins::board_folder(cache_dir, versioned) else NULL`.
  `new_gdpins_board(config, name, drive_board, local_board, cache_dir = if drive_cache cache_dir else NULL, drive_path, adapter, versioned)`.
  For fake adapter + `drive_only`, still create the scratch? No — only needed for real; create scratch
  only in the real-adapter branch (avoid stray tempdirs). For `drive_cache` always `dir_create(cache_dir)`.
- Drive-ID fast path (`# nocov` block): same rules (scratch, local_board, no cache_board/local_dir args).
- Delete every `cache_board` / `local_dir` / `has_local` / `drive_cache_local` reference in `.build_board`.

`format.gdpins_board()`: flags `[DCL]`: D = `"drive_board" %in% .config_components(cfg)`; C = `cfg == "drive_cache"`;
L = `cfg == "local_only"`. So `--L`, `DC-`, `D--`. `path_str`: `drive_path` if non-NULL, else `cache_dir`
(same 20-char truncation), else "". ≤80 cols unchanged.
`print.gdpins_board()`: after `drive =` line: if `cache_dir` non-NULL → `gd_cli_kv(local = …)` when
config `local_only`, else `gd_cli_kv(cache = …)`. Remove `local_dir` line. `drive_only` → no path line.
`summary.gdpins_board()`: same labels (`local` / `cache`) replacing `cache_dir`/`local_dir` lines.

`gdpins_init_board` roxygen (description bullets lines 201–208 only; T8 does params/examples):
```
#' - **`"local_only"`** — no `drive_path`; `cache_dir` is the local board path.
#' - **`"drive_cache"`** — `drive_path` + `adapter`; one local copy at
#'   `cache_dir` (default `NULL`/`TRUE`: `getOption("gdpins.cache_dir")/<root>/<drive_path>`).
#' - **`"drive_only"`** — `drive_path` + `adapter` + `cache_dir = FALSE`; no
#'   local copy, Drive downloads go to a session temp dir.
```
